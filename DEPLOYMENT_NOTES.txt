================================================================================
MANUAL CHECKS BEFORE SHOWING CUSTOMERS
================================================================================

1. MySQL: create database travel_agency (or rely on createDatabaseIfNotExist).
2. Set SPRING_DATASOURCE_PASSWORD (and URL/username) to match your DB.
3. Set JWT_SECRET to a long random string (at least 32 characters).
4. Set ADMIN_SEED_PASSWORD (and optionally ADMIN_SEED_EMAIL) before the first
   run if the users table is empty — or change the password after login.
5. If the public site is on a different domain than the API, set
   window.__APP_CONFIG__ in a small inline script before js/config.js, or inject
   apiBase in your hosting/CDN layer.
6. For JAR-only deployment (no file:../), copy the frontend into
   backend/src/main/resources/static/ and update spring.web.resources.static-locations
   (see backend README).
7. Replace placeholder Unsplash URLs in index.html with your own brand images
   when ready.
8. Test: start backend from backend folder, open http://localhost:8080 ,
   admin at /admin/login , API at /api/hero .
